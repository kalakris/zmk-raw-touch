The first release of zmk-raw-touch: a ZMK module that sends a keyboard
trackpad's absolute position and contact state to a host application over
USB or Bluetooth, for trackpad-style scrolling on macOS with
[RawTouch](https://github.com/kalakris/rawtouch).

## Compatibility

- **Host:** RawTouch 0.1.x. The wire protocol is version 4
  ([`docs/protocol.md`](https://github.com/kalakris/zmk-raw-touch/blob/v0.1.0/docs/protocol.md));
  hosts check it before using a keyboard.
- **ZMK:** tested on MoErgo's ZMK distribution, release `v25.11`
  (ZMK 0.3 / Zephyr 3.5).
- **Trackpad driver:**
  [`kalakris/cirque-input-module`](https://github.com/kalakris/cirque-input-module)
  `v0.1.0`, which packages Zephyr's Cirque Pinnacle driver for that tree.
- **Hardware:** verified on a MoErgo Go60 with two Cirque Pinnacle pads,
  over USB and Bluetooth, including the pad on the split peripheral
  half. Other boards need integration and testing; reports are welcome.

## Setup

Follow the [README](https://github.com/kalakris/zmk-raw-touch/blob/v0.1.0/README.md#setup),
or start from the
[Go60 starter configuration](https://github.com/kalakris/go60-rawtouch-config).
Pin this release in `west.yml` as `revision: v0.1.0`, or follow releases
with `revision: stable`.

## Known limitations

- One finger per pad: multi-touch gestures are not streamed.
- Zephyr's legacy USB stack only; `USB_DEVICE_STACK_NEXT` needs a port.
- Upstream ZMK `main` and Zephyr 4.1 are not verified.
- The firmware reports its version to the host as major.minor, so RawTouch
  announces new minor releases of the module but not patch releases.
